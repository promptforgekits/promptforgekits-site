Before you start (5 minutes)

You need three things: Node.js 18+ (LTS), Git, and an AI coding tool that opens a local folder (Cursor, Claude Code, Windsurf, or VS Code + Copilot). That's it. The game is drawn in code, so you don't need any art files.

The 4 rules that make vibe-coded games actually ship

  1. One prompt = one feature. Never ask for five things at once.
  2. Test after every change. Play it. Open the browser console (F12) and look for red errors.
  3. Commit every working step. Git is your save game.
  4. Three failed fixes = roll back. Then ask for a smaller step.

First game in 30 minutes

Minutes 0-5: scaffold. In a terminal, create a Vite project and add Phaser 3:

npm create vite@latest my-first-game -- --template vanilla
cd my-first-game
npm install
npm install phaser
git init && git add -A && git commit -m "empty project"

Open the my-first-game folder in your AI tool.

Minutes 5-10: give the AI its rules, then build a tiny platformer. Paste this as your first message:

You are helping me build a small browser game with Phaser 3 and Vite. Rules:
- One feature per step. Never change more than I ask for.
- Keep it small: a single scene is fine for now, split files only when a file passes ~200 lines.
- Put every tunable number (speed, gravity, jump power) in a config.js file as named constants.
- Draw all graphics in code with Phaser Graphics (rectangles, circles). No image files.
- After each change, tell me exactly how to test it in 1-2 sentences.
- If I paste an error, explain the cause in one sentence before you fix it.

Step 1: replace the starter content with a Phaser 3 game, 800x450, arcade physics, gravity 900. Draw a cyan circle player, an olive ground strip along the bottom, and 3 floating slate platforms. Arrow keys move left/right, Space jumps (only when standing on something). Don't add anything else.

Minutes 10-15: run it and commit.

npm run dev

Open the link Vite prints. You should see a circle you can move and jump. If it works, save your progress:

git add -A && git commit -m "step 1: player moves and jumps"

Minutes 15-25: tweak the feel. Change the numbers in config.js (speed, gravity, jump power), reload, and see what changes. Commit the version you like best.

Minutes 25-30: add one more feature of your own, test, commit. Pick something small: a coin you can collect, a spike that restarts the level, a score in the corner. Write it as one prompt, with a "how do I test it" line at the end.
