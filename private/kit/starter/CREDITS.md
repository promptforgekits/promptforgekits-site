# Credits and licenses

All game art (player, enemies, coins, spikes, flag, platforms, backgrounds, particles) is drawn in code in `src/textures.js`. It is part of the starter code and covered by the kit's `LICENSE.md`. There are no image files.

The only third-party file is the font:

| What | File | Source | License |
|---|---|---|---|
| Font: Lilita One by Juan Montoreano | `public/assets/fonts/LilitaOne-Regular.ttf` | [Google Fonts](https://fonts.google.com/specimen/Lilita+One) | SIL Open Font License 1.1, full text in `public/assets/fonts/OFL.txt` (keep it next to the font) |

The OFL lets you bundle, embed, and sell the font as part of your game. You may not sell the font file on its own, and a modified version may not use the reserved name "Lilita".

When you add art or sound, use only files you made or have a license for (CC0 packs such as kenney.nl are a safe choice), and add a row to this table.
