## Description

You've seen people build games with Cursor and Claude in an afternoon. Then you try it, and 40 prompts later the game is a black screen and the AI keeps "fixing" things that weren't broken.

The problem isn't you. It's starting from a blank folder with no structure, no rules for the AI, and no way back when things break.

**The Browser Game Starter Kit by Prompt Forge Kits gives you all three.** Open the starter in your AI tool, follow a proven prompt sequence for your genre, test after every step, and publish to itch.io when you're done.

No game dev experience needed. You'll install Node.js, run a couple of commands, and paste prompts one at a time. The guide walks you through each step.

## FAQ

**Do I need to know how to code?**
No. You need to install Node.js, run two commands, and paste prompts. The guide explains every step. Knowing some JavaScript helps but isn't required.

**Which AI tools does it work with?**
It's designed for tools that open a local project folder: Cursor, Claude Code, Windsurf, and GitHub Copilot. Lovable and Bolt run in the browser and work differently; the guide explains how to use the rules with them, but an editor-based tool gives the best results.

**Why Phaser?**
It's a mature, free, browser-first 2D engine with lots of training data, so AI tools write good Phaser code. Games run on any device with a browser.

**Can I sell games I make with it?**
Yes. You can use the starter code in your own games, including commercial ones. You can't resell or redistribute the kit itself (the starter as a template, the prompts, or the guides). Full terms are in LICENSE.md.

**Is there art or sound included?**
No image or sound files, and nothing to license. The starter's art is drawn in code (flat shapes with outlines, one consistent style described in THEME.md), so it's part of the starter code you can use in your games. The one bundled file is the Lilita One font, under the SIL Open Font License, which allows use in commercial games (`starter/CREDITS.md`). It's a clean, cohesive look for the starter, not a big asset library. The prompts show how to generate sound effects in code, and the guide shows how to swap in your own or CC0 art.

**Mac, Windows, or Linux?**
All three. You need Node.js 18 or newer.

**What if it doesn't work for me?**
If the kit didn't work for you, request a refund within 7 days of purchase. Refunds may be declined if the kit has clearly been copied or reused. Updates stay free.

**Will it be updated?**
Yes. Updates are free for life. When a new version ships, you'll get it through your Gumroad library.
