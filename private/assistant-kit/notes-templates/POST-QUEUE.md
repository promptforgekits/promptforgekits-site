# Post queue

Content adds posts as DRAFT. The owner edits and changes the status to APPROVED. Community & Launch posts only APPROVED items, exactly as written.
Statuses: DRAFT -> APPROVED -> POSTED. Or HELD (with reason) / REJECTED.

Format (copy for each post):

### P-001
Status: DRAFT
Type: post | reply (reply to: link)
Post after: YYYY-MM-DD HH:MM (time zone)
Image: none | file name + alt text
Text:
> The exact post text goes here.
Notes: why this post, source for any fact.
