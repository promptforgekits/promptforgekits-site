One prompt = one feature

Here is the single habit that separates AI-built games that ship from the ones that fall apart: ask for one thing at a time, then test it before you ask for the next.

Bad prompt: "Add enemies, a score, three levels, sound, and a menu."

Better, in four separate prompts:

1. Add one red circle enemy that walks back and forth on the ground.
2. Make the player lose when touching it. Show how to test.
3. Let the player stomp it from above. Score +25.
4. Add a score counter in the top-left corner.

After each one: play it, check the browser console (F12) for red errors, then commit with git add -A && git commit -m "step works". If three fixes in a row fail, roll back to your last commit and ask for a smaller step. Rolling back costs two minutes. Spiraling costs an evening.
