# promptforgekits.com

Marketing site for **Prompt Forge Kits** and the **Browser Game Starter Kit by Prompt Forge Kits** ($29, Gumroad + itch.io).

> Tested prompts. Real projects. Shipped.

A zero-dependency static site: plain HTML/CSS generated by one Node script (`src/build.mjs`). No framework, no client-side bundle; CSS and the ~1 KB of JS are inlined per page.

## Commands

```bash
npm run build        # -> dist/
npm run preview      # serve dist/ on http://localhost:4321
npm run sync-demos   # copy game builds into public/play/<genre>/ (then build)
```

Node 18+. No `npm install` needed.

## Where things live

| Path | What |
|---|---|
| `site.config.mjs` | **All placeholders**: store links, support email, newsletter endpoint, analytics. Search for `PLACEHOLDER`. |
| `src/content.mjs` | Product copy: what's inside, genres + prompt titles, FAQ, license summary (sourced from the kit docs) |
| `src/posts.mjs` | Blog posts |
| `src/build.mjs` | Page templates, JSON-LD, sitemap, robots, RSS, `llms.txt`, `llms-full.txt` |
| `src/styles.css` | "Chunky Flat Toy" theme (palette from THEME.md, Lilita One) |
| `src/client.js` | Click-to-load demos, newsletter form |
| `public/play/<genre>/` | Playable demo builds (`towerdefense`, `platformer`, `roguelite`, `idle`, `runner`, `puzzle`) |
| `public/img/` | WebP images (640/1280) + `og-cover.jpg` (1200x630) |
| `vercel.json` | Build settings, cache headers, `noindex` on the raw game folders |

## Refreshing the demos

Each game is a Vite project built with `base: './'`, so its `dist/` works from any subfolder.

```bash
# from the game project: npm run build
bash scripts/sync-demos.sh /workspace/prompt-tests   # or copy dist/ into public/play/<genre>/ by hand
npm run build
```

Mapping: `towerdefense-ck -> towerdefense`, and `platformer`, `roguelite`, `idle`, `runner`, `puzzle` map to themselves. A missing demo renders as "Demo coming soon".

## Before launch

1. Fill `stores.gumroad` / `stores.itch` in `site.config.mjs` (buy buttons switch from "launching soon" to live links; Product JSON-LD switches to InStock).
2. Set `supportEmail`.
3. Build the newsletter endpoint (Resend), set `newsletter.endpoint`, flip `newsletter.live: true`. The form POSTs JSON `{ email, source }`.
4. Optional: paste an analytics snippet into `analytics.headSnippet` and set `enabled: true`.
5. Attach the production domain in Vercel.
